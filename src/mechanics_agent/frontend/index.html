一条清楚的分析路径

每个页面只处理一个决定，结果和输入不会混在一起。

  1. 定义输入工况

    明确几何、材料、载荷、支承与验收目标。

  2. 检查补齐缺项

    先拦截单位、自由度和材料来源等关键问题。

  3. 规划生成行动

    结合知识库生成 CAD 与 Abaqus 操作计划。

  4. 审核工程师确认

    确认假设、风险和审批点后再进入软件执行。
