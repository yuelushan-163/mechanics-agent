# 知识规则与网格收敛使用说明（v0.5）

适用：Ansys Mechanical 2025 R2，已有独立 `.mechdat`，小变形、单步线性静力，一个标准 Force 和一个 FixedSupport。几何、材料须事先由工程人员确认。

## 本次接入

- `knowledge_catalog.json`：从《有限元Agent完整知识表》提取 90 个知识点、52 个输入字段、32 条原始规则，保存源表行号及文件 SHA256。原始 Excel 不变。条目均为 draft，供检索和解释，不能作为已审批规则或软件能力。
- `knowledge.py`：本地关键词检索；桌面对话与本地 API 可调用 `search_engineering_knowledge`，返回知识编号和来源行。无需 Elasticsearch，不执行表中内容。
- `workflow.schema.json`：当前已实现工作流的输入规范；仅启用受支持的输入，未把表中全部 52 个字段视为现有功能。
- `rules.ansys252.json`：8 项检查的来源与实现状态清单，计算器固定在 `verification.py`；修改清单不会改变程序判定逻辑。
- `benchmark_cases.json`：已执行的流程回归证据和待建立的独立力学验证案例，二者明确区分。

## 桌面操作

1. 启动新版 EXE。模型 API 地址、模型名和密钥按原流程填写；直接求解不依赖模型 API。
2. 读取模型，核对分析名称、固定面、受力面、全局载荷 N 和初始网格尺寸 mm。
3. 如需自动比较网格，勾选“启用受控网格收敛（最大总变形）”。填写相对变化阈值（小数，例如百分数应除以 100）以及依据。软件不提供通用默认阈值。
4. 设置最多 2–4 档网格和每档单元数上限。默认每档尺寸乘 0.7；这是细化步幅，不是工程合格判据。
5. 如需检查全模型最大总变形上限，填写允许值 mm 及依据；留空时只展示位移，不判定刚度是否合格。
6. 人工核对并确认运行。每档从同一个原模型开始，固定材料、载荷和边界条件。源文件变化时停止。
7. 查看对话中的规则状态，并打开输出目录的 `report.json`；各档 `mesh_01` 等目录保留模型和云图。失败及未收敛记录也保留。

## 比较与停止逻辑

比较量为同一模型全域最大总变形，统一转换为 mm。相对变化 = `abs(细网格位移 - 粗网格位移) / abs(细网格位移)`。零位移、非有限数或单元数未增加时不接受为收敛证据。

满足用户阈值时停止；超过最大档数仍未满足则标记 failed_review。网格生成后若单元数超限，在求解前保存副本并停止。网格生成自身仍有开销；工具调用整体沿用一小时超时。当前没有按秒设置预算或运行中取消功能。

支反力不平衡时停止细化。沿用当前单力模型的平衡容差 `max(1e-8 N, max(abs(Fx),abs(Fy),abs(Fz))*1e-4)`，这不是全部分析类型的通用容差。反力显式换算成 N 再比较。

规则状态为 pass / warn / block / not_applicable。运行完成、自动检查状态和工程人工验收状态分别记录；材料参数、未分类警告等仍需复核。因此位移收敛通过后也不会自动声称工程合格。

## 尚需人工处理的内容

- 当前材料检查只确认已分配，尚未自动读取、审核或验证弹性模量、泊松比、强度及来源。
- 当前只支持全域最大总变形比较；不支持指定测点、路径或区域收敛，也不验证应力收敛。
- 应力最大值保留用于观察，不直接计算强度安全系数；奇异性、平均方式和许用值须由工程人员判断。
- 局部细化、稳定语义选面、CAD 导入、接触、塑性、大变形、动力和多分析步尚未实现。本次不根据知识表自动启用它们。
- Abaqus 的 C3D8R、ODB、NLGEOM 等原始内容保留为待映射资料，不作为 Ansys 设置执行。

## 开发验证（不是项目验收）

2026-10-27 实际调用 Mechanical，原算例全局力 `[0,-1,0] N`，网格 1.0 mm 与 0.7 mm：

| 指标 | 1.0 mm | 0.7 mm |
|---|---:|---:|
| 单元数 | 4,980 | 12,558 |
| 最大总变形 mm | 6.103831080529581e-7 | 6.10492806312377e-7 |
| 最大等效应力 MPa，仅记录 | 0.012922996383237857 | 0.014258511238087824 |

位移相对变化约 0.01797%，通过此次开发测试明确设置的 1% 比较阈值；不表示项目应采用 1%，也不表示应力已收敛。原模型 SHA256 未变。证据：`runs/knowledge-convergence-validation/report.json`。

测试覆盖：阈值输入、预算与档数限制、位移超限、未收敛、相同网格、零位移、失败留痕、工况保持不变、工具输入规范与知识来源标签。

API 参考：Ansys 2025 R2 网格访问文档 https://ansyshelp.ansys.com/public/Views/Secured/corp/v252/en/act_script/act_mech_Traverse_mesh.html ；单位转换采用已安装 Mechanical 的 `units.ConvertUnit`，通过上述真实求解验证。
