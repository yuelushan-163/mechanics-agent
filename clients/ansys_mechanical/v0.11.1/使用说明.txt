Ansys 力学助手 Windows 桌面版 v0.11.1

载荷类型新增压力、力矩、重力、远程力、顶点集中力和沿边均布力。每次求解配置一个主载荷，详见“载荷类型使用说明.md”。
内置 Python 3.12.10 与固定版本离线包。保存 API 配置后，自动检查并配置环境，再由模型结合真实检查结果提供引导。详见“内置环境与首次配置说明.md”。

启动：完整解压发布包，双击 Ansys力学助手_v0.11.1.exe。请保留 _internal、runtime_payload 等随附文件。

界面采用三步分析设置：模型 → 约束与外力 → 网格与求解。右上角点击“模型 API 设置”，填写 API 地址、模型名称与密钥，先保存配置，再测试连接；右侧可切换助手对话、求解结果和运行记录。网格收敛参数按需展开，结果以数值卡片显示。

模型读取后默认打开 Mechanical 选择副本。固定支撑使用几何面过滤器；载荷按类型选择面、边或顶点，返回助手读取选区。聊天可生成参数草案，应用后再核对求解。求解结果页内显示应力、位移和载荷约束图。详细步骤见“可视化与聊天使用说明.md”和“载荷类型使用说明.md”。

右上角可切换黑夜模式/日间模式；选择会自动保存在本机，下次启动恢复。

本版本从已有 Mechanical 2025 R2 独立 .mechdat 模型开始。选择模型后，读取几何面，指定固定面、受力面、全局载荷与网格尺寸，再由程序生成网格、求解并导出结果。

运行要求：Windows x64、本机安装 Ansys Mechanical 2025 R2 及有效求解许可。无需额外安装 Python；内置环境将在当前用户目录自动展开，需要至少 512 MB 可用空间。自动识别 Ansys 失败时可在环境检查页选择 AnsysWBU.exe。Python 配置可离线完成，模型 API 仍需网络。运行环境就绪、软件连接成功、求解许可有效和工程验收通过是不同状态。

模型 API 地址和模型名保存在当前用户本机配置目录；密钥仅保存在程序内存，关闭程序后需要重新输入。
启用收敛后，在 mesh_01、mesh_02 等独立目录求解；report.json 汇总比较及规则结果。收敛阈值与依据由操作者填写，最多 2–4 档。位移收敛不代表应力收敛或工程验收。结果目录包含 case.mechdat、report.json 和可用的结果云图。源 .mechdat 不会被覆盖。

材料参数、几何面 ID、载荷含义、单位和网格收敛仍需人工确认。此程序不支持接触、塑性、大变形及多载荷步分析。
